# OnlineBakingSystem

A sample online baking system:

## Features
-User creation and admin user management
-Account management
-Basic transfer, withdrawal, and deposit functionality
-Admin transaction reconciliation

### ASP.NET API Backend

-EF Identity for user management and authorization
-JWT Authentication
-NLog for logging for system agnostic logging
